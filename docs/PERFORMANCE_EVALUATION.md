# Performance evaluation — measured 2026-10-26

Evidence: [raw CSV](../benchmarks/results/20261026T094025.091439Z/raw.csv), [summary](../benchmarks/results/20261026T094025.091439Z/summary.csv), [environment and hashes](../benchmarks/results/20261026T094025.091439Z/environment.json).

144 actual runs: 8 configurations × 3 modes × (1 warmup + 5 measured repetitions). Each worker performs 20000 iterations. Modes rotate in balanced order; configuration order is shuffled with seed 7. Every run uses the same optimized C binary. No deadlock workload enters timing. Parent supervision bounds each run to 30 seconds and verifies process-group cleanup. Counters and output correctness are checked; full file records are parsed after timing for continuous sequence, completeness, zero warnings and exact request/acquire/release totals. /dev/null discards records and cannot independently validate their delivery.

C CLOCK_MONOTONIC measures barrier release through joins; mutex initialization is excluded. Parent process-start-to-reap duration is separately recorded in raw.csv and excludes post-run JSON validation. One warmup is excluded; no slow measured samples are discarded. Percent overhead = (monitored median − baseline median) / baseline median × 100. Absolute overhead is the difference of medians, not a per-pair median.

Host: Intel Core i5-12450H, 12 logical CPUs, WSL2 kernel 6.18.33.2, GCC 15.2.0, Python 3.14.4. Workload flags: -O2 -std=c11 -Wall -Wextra -Wpedantic -pthread. Monitor uses default debug flags with no optimization. Checkout is on /mnt/c; temporary file sink is Linux /tmp, buffered without fsync. No CPU pinning or frequency control; independent counters may false-share. Short baselines and shared-host scheduling strongly affect ratios. No FastAPI or browser timing is included.

The measurements demonstrate substantial instrumentation cost: monitored times are hundreds of times the tiny baselines. They do not support a low-overhead claim or generalize to full applications. Full file and /dev/null modes both execute analysis, JSON formatting and writes. Their difference is not a pure analysis/logging decomposition. There is no reduced-logging mode. Min/max variation is retained in summary.csv; all raw samples and warmups remain available.
